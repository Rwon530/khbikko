# 👑 موقع ولوحة تحكم مطعم "كشري الزعيم" (Koshary El Zaeem)

موقع ويب احترافي متكامل 100% لمطعم كشري مصري أصيل بطابع عصري وتراثي، مع لوحة تحكم إدارية شاملة (Admin Dashboard) ونظام طلب وتتبع لحظي وحجز طاولات وطباعة فواتير كاشير حرارية.

---

## 🌟 مميزات الموقع الأساسي (Frontend)
1. **الصفحة الرئيسية (`index.html`)**:
   - Hero Section تفاعلي مع بخار متصاعد وأطباق الكشري المميزة وشعار المطعم.
   - قسم "حكاية الزعيم" وسر الصنعة المصرية منذ 1995.
   - عرض أحدث وأشهر الأطباق مع إمكانية التخصيص والإضافة الفورية للسلة.
   - عروض اليوم وبوكسات التوفير مع مؤقت عد تنازلي.
   - دليل الفروع وخريطة تفاعلية ومواعيد العمل.
   - آراء وتقييمات العملاء المعتمدة بنجوم حية.
   - قسم حجز الطاولات ودعوة لطلب الأونلاين.

2. **صفحة المنيو الكاملة (`menu.html`)**:
   - تصنيفات: (كشري الزعيم، طواجن فرن، وجبات توفير، إضافات ودقات، حلويات شرقية، مشروبات).
   - بحث فوري وفلاتر ذكية (نباتي، حار، الأكثر طلباً، عروض التوفير).
   - نافذة تخصيص الطبق (اختيار الحجم: صغير، وسط، كبير، ميجا)، واختيار الإضافات (تقلية، صلصة، شطة زيت، حمص، دقة، كبدة، موتزاريلا)، وملاحظات خاصة للشيف.

3. **نظام الطلب والسلة وطرق الدفع (`checkout.html`)**:
   - سلة مشتريات تفاعلية ومصغرة (Slide-over Drawer).
   - اختيار نوع الاستلام: **توصيل للمنزل (Delivery)** أو **استلام من الفرع (Pickup)**.
   - تحديد الفرع الأقرب ومنطقة التوصيل لحساب رسوم التوصيل تلقائياً.
   - تطبيق كوبونات الخصم (`ZAEEM2026`, `KOSHARY10`, `VIP50`) واستبدال نقاط الولاء.
   - طرق الدفع:
     - 💵 كاش عند الاستلام
     - 📱 فودافون كاش ومحافظ المحمول
     - 💳 بطاقة بنكية (فيزا / ماستركارد)

4. **التتبع اللحظي للطلب (`track.html`)**:
   - شريط تقدم تفاعلي بالمراحل: تم الاستلام ➔ في المطبخ ➔ مع كابتن التوصيل ➔ تم التسليم.
   - بطاقة بيانات كابتن التوصيل مع زر اتصال مباشر وتقدير وقت الوصول.
   - محاكي لحظي لتغيير الحالات وتجربتها.

5. **صفحات إضافية**:
   - **العروض والخصومات (`offers.html`)**: بوكسات التوفير وأكواد الخصم الجاهزة للنسخ.
   - **حجز الطاولات (`reserve.html`)**: اختيار الصالة (عائلات، تراس، شباب، VIP) وتأكيد الحجز الفوري.
   - **الوظائف (`careers.html`)**: استعراض الشواغر ونموذج التقديم الإلكتروني.
   - **تواصل معنا (`contact.html`)**: خريطة فروع تفاعلية، أرقام الخط الساخن، ونموذج المراسلة.

---

## 👑 مميزات لوحة التحكم الإدارية (Admin Dashboard - `admin.html`)
1. **الصلاحيات والأدوار (RBAC)**:
   - دعم كامل لأدوار: (المدير العام، مدير الفرع، الكاشير والمطبخ، كابتن التوصيل) مع مبدل حسابات تجريبي فوري.
2. **إدارة الطلبات الحية والتنبيهات الصوتية**:
   - استقبال وتحديث الطلبات لحظياً مع تنبيه صوتي فوري (Web Audio API Synthesizer).
   - فلترة حسب الفرع والحالة والبحث برقم الطلب أو الهاتف.
   - **طباعة بون الكاشير الحراري (POS Thermal Receipt 80mm)**: باركود، تفاصيل الأصناف، الإضافات، الخصم، والإجمالي.
3. **إدارة المنيو والمخزون**:
   - إضافة وتعديل وحذف الأصناف والأسعار.
   - تفعيل / إيقاف توفر الصنف (متوفر / نفذ من المخزون) لتحديث واجهة العملاء فوراً.
4. **التقارير والإحصائيات والرسوم البيانية (Analytics & Charts)**:
   - مؤشرات الأداء الحية (مبيعات اليوم، الطلبات النشطة، متوسط قيمة الطلب).
   - رسوم بيانية تفاعلية (منحنى المبيعات الأسبوعية، أكثر الأطباق مبيعاً).
   - جدول مقارنة أداء الفروع.
   - تصدير تقارير الطلبات إلى ملف Excel / CSV.
5. **إدارة العملاء ونقاط الولاء (Loyalty CRM)**:
   - سجل العملاء وإجمالي المشتريات ونقاط المكافآت وشرائح العضوية.
   - مرسل حملات العروض المباشرة عبر WhatsApp Web.
6. **إدارة الحجوزات والوظائف والموظفين والإعدادات العامة**.

## 🚀 كيفية تشغيل المشروع

### تشغيل عبر Python السريع:
```bash
python server.py
```
افتح المتصفح على:
- الموقع الرئيسي: `http://localhost:8000/index.html`
- قائمة المنيو: `http://localhost:8000/menu.html`
- لوحة التحكم الإدارية: `http://localhost:8000/admin.html`
- تتبع الطلب: `http://localhost:8000/track.html`

أو يمكنك فتح أي ملف `.html` مباشرة في متصفح الويب.
